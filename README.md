## 💻 Getting Started <a name="getting-started"></a>

To get a local copy up and running, follow these steps.

### Prerequisites

In order to run this project in your local machine you should have node.js installed in your local machine.

### Setup

Clone this repository to your desired folder:

```sh
  git clone git@github.com:Al-Amin-Khan-Shakil/viva-la-pizza.git
  cd viva-la-pizza
```

### Install

Install this project with:

```sh
  npm install
```

### Usage

To run the project, execute the following command:

```sh
  npm run dev
```
